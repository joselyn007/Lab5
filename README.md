# Laboratorio: APIs REST con Spring Boot

- **Estudiante:** Joselyn Pamela Ambrocio Chanax 
- **Descripción:** Desarrollo de 10 APIs REST independientes con operaciones CRUD completas y almacenamiento en memoria utilizando Spring Boot, Maven y Java.

## Estructura del Proyecto
- `src/main/java/com/lab/apis/controller/`: Contiene los 10 controladores REST.
- `src/main/java/com/lab/apis/model/`: Contiene los 10 modelos de datos.

## Pruebas
Las pruebas de los endpoints (GET, POST, PUT, PATCH, DELETE) se realizaron en **Postman**. La colección exportada se encuentra en la raíz del repositorio.
